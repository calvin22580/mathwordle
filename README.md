# Sum Sleuth

A daily maths-equation guessing game for iOS, Android and the web. Players have
six guesses to find a hidden equation such as `9÷3×9=27`; each tile turns green
(right character, right place), purple (in the equation, wrong place) or grey
(not in it).

The app name and store details live in [`brand.json`](brand.json).

## Repository layout

```
brand.json            app name, share text, store identifiers (single source)
shared/
  game-config.json    guess limit and tile counts per difficulty
  test-vectors/       cases both engines must agree on (generated by Python)
backend/              FastAPI server (Python)
  app/engine/         the rules: validator, scorer, answers, daily picker, clues
  tests/
packages/engine/      the same rules in TypeScript, for the app
app/                  Expo app for iOS, Android and the web
  src/app/            screens (Expo Router): home, practice, settings, tutorial
  src/components/     board, tiles, keypad, clue panel, confetti, result card
  src/state/          game logic hook, settings (saved on the device)
  src/theme/          light, dark and colour-blind palettes, text sizes
  src/services/       haptics, sounds, brand
```

The API routes and daily puzzle arrive in a later phase.

## Running the app

Needs Node 20 or newer. From the repo root:

```
npm install
cd app
npx expo start
```

Then:

- **On your phone:** install Expo Go from the App Store or Google Play and scan
  the QR code in the terminal. Phone and computer must be on the same Wi-Fi
  (or run `npx expo start --tunnel`).
- **In a browser:** press `w`, or run `npx expo start --web`.

Physical keyboards work on the web: digits, `+ - * / x =`, Enter and Backspace.

Practice mode works fully offline. Settings (theme, colour-blind colours, text
size, sounds, vibration) and any unfinished practice game are saved on the
device.

### Building for iPhone with Xcode (macOS)

Needs Xcode and CocoaPods. From the repo root:

```
npm install
cd app
npx expo prebuild --platform ios --clean   # writes the Xcode project to app/ios
npx expo run:ios                            # builds and opens the Simulator
```

`app/ios` is generated, so it isn't committed; rerun `prebuild --clean` after
changing `app.config.ts`, `brand.json` or native packages.

### Sending a build to TestFlight

1. In `app/app.config.ts`, raise `BUILD` by one for every upload (and `VERSION`
   for each new App Store release).
2. Run `npx expo prebuild --platform ios --clean`, then open
   `app/ios/SumSleuth.xcworkspace` in Xcode.
3. In the SumSleuth target's *Signing & Capabilities*, pick your team.
4. Choose *Any iOS Device (arm64)*, then *Product → Archive*.
5. In the Organizer, *Distribute App → App Store Connect → Upload*.
6. The build appears in App Store Connect under TestFlight after processing
   (usually 5 to 30 minutes).

The first upload needs the app to exist in App Store Connect
(*Apps → + → New App*) with the bundle ID from `brand.json`.

## The game engine

The Python engine in `backend/app/engine` is the reference. The server uses it
to pick daily answers and score guesses. The TypeScript engine in
`packages/engine` lets the app reject untrue guesses instantly and run practice
mode offline. Both run against the vectors in `shared/test-vectors`, so they
cannot drift apart.

Rules the engine enforces:

- Easy is 5 tiles, Medium 6, Hard 8. Characters are 0–9, `+ − × ÷ =`.
- A guess must be a true equation of the right length: exactly one `=`, at least
  one sign on the left, a single non-negative whole number on the right, no
  leading zeros, no negative numbers, no two signs in a row, no dividing by 0.
  × and ÷ come before + and −, each left to right. Anything else is rejected
  with a plain-English reason.
- Colours follow the usual duplicate rule: greens first, then purples left to
  right, only up to the copies of that character not already matched.
- Hidden answers are stricter: whole-number division at every step, every
  running total 0 or more, and no boring answers (no 0 in the sum, no ×1, ÷1 or
  a number divided by itself, the answer isn't 0 and doesn't repeat a number
  from the sum). That leaves 78 Easy, 195 Medium and 14,998 Hard answers.
- Daily answers are a secret-keyed shuffle of the full list, so none repeats
  until all have been used.

## Running the tests

Python (3.11 or newer):

```
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest
```

TypeScript (Node 20 or newer):

```
npm install
npm test
npm run typecheck
```

After a deliberate rule change, regenerate the shared vectors and review the
diff:

```
cd backend && python -m app.engine.vectors
```
